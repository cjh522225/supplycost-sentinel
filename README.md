# 链价智控

**供应链成本监测与动态调价预警智能体**

链价智控是一套面向铝合金压铸、金属材料采购与供应链成本管理场景的 Windows 桌面应用。它将中国人民银行汇率中间价、上海有色网（SMM）铝合金/镁合金价格、中国外汇交易中心（CFETS）校验数据聚合到本地，经过统一校验后计算日、月、季、半年、年均值，并以面板、预警、审计和 AI 分析的方式呈现。所有业务数据以 JSON/CSV 保存在本地，不使用数据库，不依赖后台服务，默认不自启。

## 解决的问题

- **数据分散**：汇率、铝价、镁价分布在央行、外汇交易中心、有色网和行业网站，人工汇总耗时且容易漏采。
- **口径不一**：不同来源的报价单位、报价方向、日期和精度不同，直接混算会产生错误结论。
- **缺乏追溯**：Excel 手工表难以证明某个均值由哪些原始记录、按什么公式计算得出。
- **响应滞后**：采购和报价人员通常在成本已经变化后才发现，缺少阈值预警和解释。
- **合规边界**：部分行业网站存在会员或反爬限制，不能以非授权方式自动抓取。

链价智控的处理原则是：**官方源自动采集、可校验数据才进入展示层、计算过程可追溯、本地文件可审计、监测对象可动态配置**。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 官方数据聚合 | 自动抓取 PBOC 人民币汇率中间价与 SMM 铝合金/镁合金价格；CFETS 作为汇率交叉校验源 |
| 数据校验门禁 | 字段、日期、数值、单位、来源域名、合理区间、日波动、多源偏差、重复冲突共九类检查；失败记录进入隔离区 |
| 多级均值 | 每日加工均值 → 月度均值 → 季度均值 → 半年度均值 → 年度均值；高周期均值按“每日加工均值等权”计算 |
| 精度可控 | 原始值与聚合值均以十进制字符串保存；Decimal.js 中间计算精度 50；显示按标的精度四舍五入 |
| 本地持久化 | 原始/有效/隔离/聚合保存 JSON + CSV；预警/审计保存 JSON；按月/年自动分卷 |
| 跨卷查询 | 历史查询自动读取并拼接多个年度/月度文件，无需数据库 |
| 动态监测配置 | 支持停用 EUR、增加 GBP、将 AZ91D 替换为 AM60B 等配置变更，面板随配置实时重构 |
| 预警中心 | 阈值突破、日波动、月均偏离、数据 stale、无数据、抓取失败、隔离数据等预警；支持确认与解决 |
| 数据审计 | 抓取日志、校验日志、轮转日志、文件清单、隔离区复核，形成可展示的证据链 |
| AI 分析助手 | 支持日报、预警解释、流式对话和本地对话历史；无 Key 或请求失败时使用本地模板兜底，数字只来自有效数据 |
| AI 日报 | 支持手动生成；开启“抓取后自动生成”后按日保存到 `data/reports` |
| 实时行情参考 | 可选第三方报价/买价/卖价/深度/成交面板；支持额度显示、自动降频与 429 退避；无 Key 时可启用明确标注的演示行情，不进入官方均值 |
| Windows 交付 | Electron + NSIS 安装包，按用户安装，默认不自启，不注册系统服务 |

## 快速开始

### 环境要求

- Windows 10/11 x64
- Node.js 22 LTS（开发与构建）
- npm 10 或更高版本
- 可访问 PBOC、CFETS、SMM 的网络环境

安装版用户不需要安装 Node.js。

### 命令

```powershell
npm install
npm run dev
npm run backfill
npm test
npm run package
```

| 命令 | 用途 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 启动 Electron + Vite 开发环境 |
| `npm run dev:local` | 本地开发模式，关闭调度，避免自动抓取改写本地数据 |
| `npm run backfill` | 按设置中的起始日期回填历史数据，写入本地 JSON/CSV 并计算多级均值 |
| `npm test` | 运行 Vitest 测试 |
| `npm run typecheck` | 运行主进程与渲染进程 TypeScript 类型检查 |
| `npm run package` | 构建并生成 NSIS 安装包，输出到 `dist/` |
| `npm run package:dir` | 生成未打包目录，便于排查安装包问题 |
| `npm run verify` | 运行独立校验脚本（需要 Python 环境） |

### 本地开发 → 测试 → 打包

1. `npm run dev:local`：启动 Electron + Vite，关闭定时调度，热更新开发。
2. `npm test`：运行 88 项 Vitest 单元测试。
3. `npm run typecheck`：主进程与渲染进程 TypeScript 检查。
4. `npm run verify`：独立 Python 校验本地 JSON/CSV 与均值。
5. `npm run package`：确认功能稳定后再生成 NSIS 安装包，输出到 `dist/`。

`data/` 与 `config/` 是本地开发数据目录；`dist/` 只是构建产物，可随时重新生成。

首次运行建议顺序：

1. 启动应用，确认数据目录与默认监测标的。
2. 在“设置”中确认调度时间、校验阈值和精度。
3. 执行历史回填；数据量较大时建议分批进行。
4. 在“总览”查看最新值与各级均值，在“历史与均值”核对计算追溯。
5. 在“验收模式”逐项检查本地文件、轮转、跨年查询和动态配置。

默认数据目录为应用工作目录下的 `data/`。安装版可在“设置”中查看实际绝对路径，并通过“打开数据目录”定位。安装包输出示例：`dist/链价智控-安装包-1.0.0.exe`。

## 数据源与采集方式

| 数据源 | 指标 | 采集方式 | 说明 |
| --- | --- | --- | --- |
| 中国人民银行（PBOC） | EUR、USD、GBP、JPY、HKD 等人民币汇率中间价 | 自动抓取 | 解析每日“人民币汇率中间价公告”；报价统一为 1 单位外币兑人民币，JPY 由 100 日元折算 |
| 中国外汇交易中心（CFETS） | 人民币汇率中间价 | 自动抓取，交叉校验 | 不直接进入展示主序列；用于与 PBOC 同日数据比对 |
| 上海有色网（SMM） | ADC12、AZ91D、AM60B 等 | 自动抓取公开 `history_price` 接口 | ADC12 产品 ID `201102250397`；AZ91D `202004280003`；AM60B `202004280005` |
| 亚洲金属网（Asian Metal） | ADC12、AZ91D | 手动录入 / CSV 导入 | 因会员与公司限制无法自动抓取；按赛题说明保留本地录入接口，不自动登录、不绕过限制 |

### Asian Metal 说明

Asian Metal 数据采用“手动录入 + CSV 导入”双模式，不进行自动登录或会员内容绕过。手动录入支持填写日期、产品、最低价、最高价、均价、单位、来源链接和备注；未填写均价时，由最低价与最高价的中点生成均价。CSV 导入使用 UTF-8 编码，列名支持中英文别名。所有手动数据仍需经过与自动数据相同的校验流程，未通过校验的记录进入隔离区，不进入展示层。

详细列名与导入规则见 [数据格式说明](docs/数据格式说明.md) 和 [部署手册](docs/部署手册.md)。

## 计算与数据可信

1. **原始留存**：抓取结果先写入 `data/raw/<source>/<年>/<月>.json` 与同名 CSV，保留来源 URL、抓取时间、内容哈希和解析器版本。
2. **校验门禁**：校验通过进入 `data/validated/`，失败进入 `data/quarantine/`。展示层和聚合只读取有效数据。
3. **每日加工均值**：同一天同一监测标的的多条有效记录先取算术平均，形成该日加工值。
4. **高周期均值**：月、季、半年、年均值均以“每日加工均值等权”计算，不按原始记录条数加权，也不对已四舍五入的月均值再次求平均。
5. **精度控制**：中间计算使用 Decimal.js（precision=50，ROUND_HALF_UP），聚合结果保存为全精度字符串，界面按标的精度显示；不使用 JavaScript 浮点数做金额计算。
6. **可追溯**：每条聚合记录包含 `sum`、`count`、`min`、`max`、`coverage`、`partial`、`computedAt`、`formulaVersion` 与 `sourceFiles`，可在“历史与均值”中查看日明细和公式。

## AI 助手

智能分析支持对话、日报和预警解释三种模式。语言模型只接收本地有效数据与聚合结果，回答中的数字来自本地数据；请求失败或未配置 Key 时，系统使用模板生成可读报告，不编造行情。

| 预设 | Base URL | 默认模型 | 协议 |
| --- | --- | --- | --- |
| OpenCode Go | `https://opencode.ai/inference/go/openai/v1` | `deepseek-v4.1-flash` | OpenAI 兼容 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | OpenAI |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | OpenAI 兼容 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | OpenAI 兼容 |
| Anthropic Claude | `https://api.anthropic.com` | `claude-3-5-sonnet-latest` | Anthropic Messages |
| 自定义 | 用户填写 | 用户填写 | OpenAI 兼容 |

API Key 通过 Electron `safeStorage` 使用当前 Windows 用户的系统凭据加密，不以明文写入源码、日志或导出文件。未配置 Key 时 AI 功能仍可使用模板兜底。

## 典型工作流

1. **首次启动**：确认数据目录、默认监测标的与调度时间。
2. **历史回填**：抓取 PBOC 与 SMM 历史数据，手动/CSV 补录 Asian Metal 数据。
3. **日常监测**：应用在设定时间抓取当日数据；错过执行时，按 `catchUp` 配置在下次启动补跑。
4. **查看均值**：在总览查看六张监测卡；在历史与均值切换日/月/季/半年/年，查看计算追溯。
5. **处理预警**：在预警中心确认或解决阈值、波动、月均偏离、数据 stale 等预警。
6. **审计与验收**：在数据审计查看抓取/校验/轮转日志与隔离区；在验收模式逐项核验。
7. **AI 复盘**：生成日报、解释预警，或就均值变化提问。
